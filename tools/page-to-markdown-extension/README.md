# Duni Page to Markdown

Extension Chrome Manifest V3 để xuất popup/modal, nội dung chính hoặc phần văn bản đã chọn thành file Markdown. Dữ liệu chỉ được xử lý trong trình duyệt và không gửi đến máy chủ bên ngoài.

## Cài đặt

1. Mở `chrome://extensions`.
2. Bật **Chế độ dành cho nhà phát triển**.
3. Chọn **Tải tiện ích đã giải nén**.
4. Chọn thư mục `tools/page-to-markdown-extension`.
5. Ghim extension **Duni Page to Markdown** lên thanh công cụ.

## Sử dụng

- Mở trang ACB cần lấy tài liệu và mở đúng popup/API cần xem.
- Nhấn extension rồi chọn **Tải nội dung hiện tại**.
- Nếu chỉ cần một phần, bôi đen nội dung trước rồi chọn **Tải phần đã chọn**.
- Có thể dùng `Alt + Shift + M` để tải nhanh nội dung hiện tại.

Extension tự ưu tiên dialog/modal đang hiển thị, rồi mới đến `main`, `article` hoặc toàn bộ trang.
